Solo, side by side or online

All three are in the same game: pick one from the menu once it starts. The same match every way.

  • Against the CPU

    On your own, a quick match or a tournament. Three difficulty levels; difficulty only changes how well the computer decides.

  • Two players, one computer

    Side by side with a friend, one team each: P1 on the keyboard (or a gamepad), P2 on a gamepad. The AI plays your teammates.

  • Online New

    One of you opens a room, the other joins with its six-letter code or an invite link. The link opens in the browser, so your friend needs to download nothing; browser and desktop play each other. Rematch on the same connection.

    No account, no ranking, no stats — just the match.

Play football, don't manage it

The only edge is playing better. No menu setting or meta-strategy puts anyone ahead before kickoff.

  • Equal players

    No pace, shooting or height stats. Shirt numbers 1–11 are identity only.

  • No condition systems

    No stamina, form, morale or injuries that change how the match plays.

  • No progression, no pay-to-win

    No XP, levels or upgrades, and nothing to buy that helps you win. A long-time player is better only because they play better.

  • No tactics management

    No sliders or instructions. A few balanced formations, locked for the match.

  • No hidden modifiers

    No momentum scripting or home advantage. Rain only lets the ball run a touch further and bounce a touch lower, for both sides alike.

  • Small control set

    Move, pass, through, lob, shoot, skill, switch. Title → pick teams → kick off.

Difficulty only changes how well the CPU decides — never the physics, never your teammates.

Windows

x64 · ~95 MB zip · no installer

Download for Windows
  1. Unzip anywhere and run NonameSoccer.exe. Keep the files in the folder together (online play needs them).
  2. If SmartScreen warns: More info → Run anyway.

macOS

Universal · ~120 MB zip · Apple Silicon + Intel

Download for macOS
  1. Unzip, then Control-click the app → Open → Open.
  2. If macOS says it is damaged, run this in Terminal:
xattr -dr com.apple.quarantine "Noname Soccer.app"
